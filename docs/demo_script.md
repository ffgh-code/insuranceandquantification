# 三分钟项目演示脚本

## 演示流程（约 3 分钟）

### 00:00-00:20 开场与项目定位

**口播：** 大家好，这是我基于沪深300真实行情构建的 LLM 新闻情绪增强 GARCH 波动率预测系统。项目把大语言模型情绪分析与传统计量模型结合起来，跑通了一条从新闻到波动率预测再到精算应用的全链路。

**画面：** 打开 GitHub 仓库主页，展示 README 架构图。

### 00:20-00:50 数据与情绪分析

**口播：** 数据来自 akshare 拉取的沪深300指数 727 个交易日真实行情。情绪分析是项目的核心创新：我们通过 LLM 对中文财经新闻打分，按来源加权聚合（监管公告权重最高），并拆分为正向、负向两条独立时间序列。

**画面：** Dashboard 切换到 Sentiment Analysis 页面，展示情绪分布、方向占比、话题分类。

### 00:50-01:20 波动率模型

**口播：** 波动率建模采用了五个模型家族：四种已实现波动率估计量、5分钟高频日内波动率、GARCH 族模型、ARIMA 基线，以及 LSTM 和注意力 Transformer。GARCH(1,1) 在真实数据上 AIC 为 2030，条件波动率与 Yang-Zhang 估计量高度吻合。

**画面：** 展示 Volatility Models 页面，GARCH 条件波动率与已实现波动率对比图。

### 01:20-01:50 回测与对照组

**口播：** 回测采用滚动窗口设计，240天窗口按月刷新参数，7:3 训练测试划分。五组对照组包括 ARIMA、原生 GARCH、GJR-GARCH、纯情绪策略和 GARCH-X 综合策略。综合策略夏普 0.43，在三行情子集中验证了 A 股趋势性更强的市场结构特征。

**画面：** Rolling Backtest Report 页面 + 五组对照组指标表。

### 01:50-02:30 精算应用

**口播：** 项目最大的差异化亮点在精算拓展。Solvency II / C-ROSS 双框架下，GARCH 波动率自动导入 SCR 计算，动态方案比静态计提释放 15%-30% 闲置资本。动态损失准备金在极端行情下缺口概率显著低于固定 35% 计提。GARCH 增强 Lee-Carter 死亡率模型在 MAE 和 RMSE 上均优于基线。

**画面：** Solvency Simulation + Reserving Comparison 页面。

### 02:30-03:00 总结与链接

**口播：** 总结一下：项目验证了情绪增强波动率预测在 A 股市场的有效性，识别了中美市场结构差异，并把量化方法落地到保险精算实务。代码、研究报告和在线 Demo 都在 GitHub 上，欢迎查看。

**画面：** GitHub 仓库 + Streamlit 在线 Demo 链接。
