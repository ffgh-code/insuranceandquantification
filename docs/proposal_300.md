# 大创课题申报简介

## 课题名称：基于LLM情绪因子与波动率模型的保险资管资产负债风险管理研究

**研究背景**
保险资金运用规模已超30万亿元，资产负债匹配管理面临利率波动、权益市场震荡的双重压力。传统资产负债管理依赖静态假设，缺乏对市场情绪传导的实时捕捉能力。大语言模型在金融情绪分析领域的突破，为保险资管风险管理提供了新的技术路径。

**研究内容**
本课题构建"LLM情绪因子-GARCH波动率模型-偿付能力动态测算"三层框架：（1）利用大语言模型对宏观政策新闻、行业动态进行实时情绪打分，构建正向/负向情绪因子时序；（2）将情绪因子作为外生变量引入GARCH-X模型，提升条件波动率预测精度；（3）将波动率预测自动导入Solvency II / C-ROSS偿付能力计算体系，实现保险公司市场风险SCR的动态估算与压力测试。

**创新点**
一是将LLM情绪分析与精算偿付能力测算打通，同类研究尚属空白。二是建立波动率驱动的动态损失准备金计提机制，替代传统固定比例计提。三是引入GARCH波动率聚集效应改良Lee-Carter死亡率预测模型。

**预期成果**
完整开源代码框架一篇、研究报告一份、可交互Streamlit演示系统一套。为保险资产管理机构提供市场情绪驱动的资产负债风险预警工具原型。

**应用价值**
直接服务于保险公司的资产负债匹配管理、偿付能力资本计量和动态准备金评估等核心精算实务场景。
